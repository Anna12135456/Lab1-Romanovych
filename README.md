
# Sports League Analyzer

## Призначення програми

Програма Sports League Analyzer призначена для аналізу результатів матчів спортивної ліги. Вона читає дані з CSV-файлу, перевіряє правильність записів, обчислює статистичні показники та формує звіт.

## Формат вхідних даних

Кожен рядок містить п'ять полів, розділених крапкою з комою:

`home;away;homeScore;awayScore;attendance`

- `home` — назва домашньої команди;
- `away` — назва гостьової команди;
- `homeScore` — кількість голів домашньої команди;
- `awayScore` — кількість голів гостьової команди;
- `attendance` — кількість глядачів.

Файл повинен мати кодування UTF-8. Кількість голів і глядачів має бути цілим невід'ємним числом.

## Статистичні показники

1. Середня кількість голів за матч.
2. Найбільша відвідуваність.
3. Сумарна відвідуваність.

## Компіляція та запуск

Для роботи потрібна Java 17 або новіша.

Компіляція:

```bash
javac Main.java
```

Звичайний запуск:

```bash
java Main
```

Запуск із власним вхідним файлом:

```bash
java Main --input data/input.csv
```

Збереження звіту у вказаний файл:

```bash
java Main --input data/input.csv --output data/report.txt
```

Довідка:

```bash
java Main --help
```

Перегляд версії:

```bash
java Main --version
```

## Приклад вхідних даних

```text
Dynamo;Shakhtar;2;1;15000
Barcelona;Real Madrid;3;3;85000
Arsenal;Chelsea;1;0;60000
```

Програма пропускає неправильні записи, повідомляє номер рядка та причину помилки, а потім продовжує обробку.

## Результат

Звіт містить кількість коректних матчів, середню кількість голів, найбільшу та сумарну відвідуваність.
